## Rules for this branch

- Test builds are `3.0.N` (`plugin/src/lc_version.h` + `addon/Scripts/Game/LC/LC_Version.c`). Testing is
  local only (Workbench / own server); never published.
- Bugfixes start on `main`, never here. After each bugfix release, **merge** `main` into this branch (no
  rebase; the branch is pushed).
- Protocol: first incompatible bridge change sets `LC_PROTOCOL_VERSION` and
  `LC_GameStateWriter.PROTOCOL_VERSION` to main's + 1; re-bump after any merge that brings a higher one.
- Unreleased 3.0 section at the top of `CHANGELOG.md` once there is anything user-facing.
- Workspace habits apply: GOTCHAS + vanilla grep before Enforce code, `enforce_check` after,
  `reforger_triage_logs` after any run, never claim "compiles/works" without log evidence.
